Thingamalogger is an ID catalogging tool for the game Eternity Egg. I made it and it kicks ass!

My first public coding project, so expect some bugs. Feel free to write them in the issues tab and they may end up fixed.

Windows users can get the latest release in the releases page. For compiling I've included a .bat you can use that should 
autogenerate all the needed files. If your on Mac or Linux your SOL cause I don't use those...
